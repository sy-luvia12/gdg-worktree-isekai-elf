# 🧝‍♀️ 이세계 엘프들

> 일상에서 만난 식물을 사진으로 수집하고, 실제로 키우는 식물까지 기록하며 식물과 친해지는 게임형 식물 라이프로그 앱입니다.

**GDGoC KU Worktree 프로젝트**

## 프로젝트 소개

식물은 일상에서 쉽게 만날 수 있지만 이름과 특징을 모르면 그냥 지나치기 쉽고, 직접 키우기 시작하면 관리 방법을 몰라 어려움을 겪기도 합니다. 이세계 엘프들은 식물 사진 인식과 도감 수집, 가벼운 게임 요소, 반려식물 기록을 통해 식물에 대한 관심을 자연스럽게 이어가도록 돕습니다.

사용자는 주변 식물을 촬영해 이름과 정보를 알아보고, 발견한 식물을 도감에 저장합니다. 실제로 키우는 식물은 따로 등록해 상태와 돌봄 기록을 남길 수 있도록 하는 것이 프로젝트의 방향입니다.

## 기획 의도와 사용자

- 식물과 자연에 관심은 있지만 전문 지식이 부족한 사람
- 산책, 등하교, 여행 중 일상의 사진과 기록을 남기는 사람
- 반려식물을 키우고 싶지만 관리 실패가 걱정되거나 경험이 적은 사람

앱은 식물을 어렵게 공부시키기보다, 발견하고 수집하는 즐거움을 통해 이름과 특징을 자연스럽게 알아가도록 돕습니다. 반려식물 관리에서는 정해진 물 주기만 알리기보다 흙과 잎의 상태를 살펴보는 습관을 만드는 것을 지향합니다.

## 핵심 사용자 흐름

1. 일상에서 식물을 발견하고 사진을 촬영하거나 사진을 업로드합니다.
2. 식물 이름 후보와 간단한 정보를 확인합니다.
3. 식물을 내 도감에 저장하고 사진, 날짜, 메모를 기록합니다.
4. 수집 경험을 쌓고, 이후 반려식물의 상태와 돌봄 기록도 관리합니다.

## MVP 범위

### 우선 구현할 기능

- 회원가입 및 로그인 (이메일·소셜·익명 로그인 방식은 추후 확정)
- 최근 수집 식물을 볼 수 있는 홈 화면
- 카메라 촬영 또는 갤러리 사진 업로드
- 외부 식물 식별 API를 이용한 이름 후보와 신뢰도 표시
- 식물 이름, 학명, 간단한 설명과 특징 표시
- 식물함에 발견한 식물을 카드로 저장
- 사진, 날짜, 식물명, 메모가 포함된 수집 기록

### 이후 확장 후보

- 식물 수집 경험치와 수집 수에 따른 칭호
- 실제 키우는 반려식물 등록
- 물 주기 지시보다 흙·잎 상태 확인을 유도하는 알림
- 물 주기, 흙·잎 상태와 메모를 남기는 돌봄 기록

확장 후보는 MVP 구현과 팀의 우선순위 결정 뒤 범위를 확정합니다.
