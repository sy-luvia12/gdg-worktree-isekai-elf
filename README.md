# 🧝‍♀️ 이세계 엘프들

> 일상에서 식물을 발견하고, 사진으로 알아보고, 나만의 도감에 모으는 게임형 식물 라이프로그 앱

**GDGoC 26-2 Worktree Project**

## 프로젝트 소개

식물에 관심은 있어도 이름이나 특징을 몰라 지나치기 쉽고, 직접 키우기 시작하면 관리 방법을 몰라 어려움을 겪습니다. 이세계 엘프들은 식물을 공부해야 하는 대상으로 만들기보다, 산책이나 등하교 중 발견한 식물을 가볍게 알아보고 모으면서 자연스럽게 친해지도록 돕습니다.

사진으로 식물을 식별해 도감에 저장하고, 내가 키우는 식물은 상태와 돌봄 기록을 남기는 모바일 앱입니다.

## 주요 사용자

- 식물과 자연에 관심은 있지만 전문 지식은 많지 않은 사람
- 산책, 등하교, 여행 중 사진과 기록을 남기는 것을 좋아하는 사람
- 반려식물을 키우고 싶지만 관리 실패가 걱정되는 사람

## 핵심 경험

1. 일상에서 식물을 발견하고 사진을 찍습니다.
2. 식물 이름 후보와 간단한 정보를 확인합니다.
3. 발견한 식물을 사진, 날짜, 메모와 함께 내 식물함에 저장합니다.
4. 실제로 키우는 식물은 따로 등록해 상태와 돌봄 기록을 남깁니다.

## MVP 기능

- 회원가입 및 로그인
- 홈 화면에서 최근 수집한 식물 확인
- 카메라 촬영 또는 갤러리 사진 업로드
- 식물 식별 결과와 신뢰도 확인
- 식물 이름, 학명, 설명 및 특징 확인
- 식물함에 수집 카드와 기록 저장

### 이후 확장 후보

- 수집 경험치와 칭호
- 반려식물 등록 및 상태 확인 알림
- 물 주기, 흙·잎 상태, 메모를 포함한 돌봄 기록
