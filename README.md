# 🧝‍♀️ 이세계 엘프들

> 일상에서 만난 식물을 사진으로 수집하고, 실제로 키우는 식물까지 기록하며 식물과 친해지는 게임형 식물 라이프로그 앱입니다.

**GDGoC KU Worktree 프로젝트**

## 프로젝트 소개

식물은 일상에서 쉽게 만날 수 있지만 이름과 특징을 모르면 그냥 지나치기 쉽고, 직접 키우기 시작하면 관리 방법을 몰라 어려움을 겪기도 합니다. 이세계 엘프들은 식물 사진 인식과 도감 수집, 가벼운 게임 요소, 반려식물 기록을 통해 식물에 대한 관심을 자연스럽게 이어가도록 돕습니다.

사용자는 주변 식물을 촬영해 이름과 정보를 알아보고, 발견한 식물을 도감에 저장합니다. 실제로 키우는 식물은 따로 등록해 물 주기 같은 돌봄 기록을 남기고, 그 기록을 바탕으로 AI가 식물 상태를 살펴보는 기능도 검토하고 있습니다.

## 기획 의도와 사용자

- 식물과 자연에 관심은 있지만 전문 지식이 부족한 사람
- 산책, 등하교, 여행 중 일상의 사진과 기록을 남기는 사람
- 반려식물을 키우고 싶지만 관리 실패가 걱정되거나 경험이 적은 사람

앱은 식물을 어렵게 공부시키기보다, 발견하고 수집하는 즐거움을 통해 이름과 특징을 자연스럽게 알아가도록 돕습니다. 반려식물 관리에서는 정해진 물 주기만 알리기보다 흙과 잎의 상태를 살펴보는 습관을 만드는 것을 지향합니다.

## 핵심 사용자 흐름

1. 일상에서 식물을 발견하고 사진을 촬영하거나 사진을 업로드합니다.
2. 식물 이름 후보와 간단한 정보를 확인합니다.
3. 식물을 내 도감에 저장하고 사진, 날짜, 메모를 기록합니다.
4. 수집 경험을 쌓고, 이후 반려식물의 상태와 돌봄 기록도 관리합니다.

## 기능 범위

> 1차 회의에서 '내 식물 관리(식집사)' 기능이 추가되면서 기능 우선순위를 다시 정하는 중입니다. 최신 목록과 우선순위는 Notion의 [MVP 페이지](https://app.notion.com/p/3ebc726851c780fe99eaec74a2102162)를 기준으로 합니다.

### MVP (처음 기획)

- 회원가입 및 로그인 (방식과 시점은 논의 중)
- 최근 수집 식물을 볼 수 있는 홈 화면
- 카메라 촬영 또는 갤러리 사진 업로드
- 외부 식물 식별 API를 이용한 이름 후보와 신뢰도 표시
- 식물 이름, 학명, 간단한 설명과 특징 표시
- 식물함에 발견한 식물을 카드로 저장
- 사진, 날짜, 식물명, 메모가 포함된 수집 기록

### 우선순위 논의 중

| 분류 | 기능 |
| --- | --- |
| 내 식물 관리 | 내 식물 등록·이름 붙이기, 물 주기·영양제·분갈이 관리, 돌봄 기록, 상태 확인 알림, 날씨 연동 |
| AI 건강 검진 | 사진과 돌봄 기록으로 식물 상태 진단 |
| 수집·게임 요소 | 도감 채우기, 식물 캐릭터, 같은 식물을 여러 번 찍으면 진화, 경험치·칭호 |
| 소셜 | 게스트 모드, SNS 공유, 친구 기능, 커뮤니티 질문 |

## 기술 스택과 개발 환경

아래는 현재 계획 중인 스택입니다. 로그인 방식, 스타일 도구, 건강 검진에 쓸 AI는 아직 정하는 중이며, 확정되면 이 표와 실행 안내를 갱신합니다.

| 영역 | 기술 | 상태 |
| --- | --- | --- |
| 앱 | Expo + React Native + TypeScript (iOS·Android) | 계획 |
| 화면 이동 | Expo Router | 계획 |
| 스타일 | NativeWind 또는 기본 StyleSheet | 논의 중 |
| 백엔드 / DB | Supabase (Postgres · Auth · Storage) | 계획 |
| 서버 로직 | Supabase Edge Functions (외부 API 키는 여기서만 사용) | 계획 |
| 식물 식별 | Pl@ntNet API | 계획 |
